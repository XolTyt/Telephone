# Проверка ClearCall — 17 ноября 2026

Движок: @metered-ca/realtime 1.2.1. Сайт остаётся собственным приложением ClearCall на Vercel. В конфигурацию включён предоставленный владельцем publishable key; это не секретный sk_-ключ.

Пройдено:

- TypeScript (`tsc --noEmit`).
- 37 модульных/компонентных тестов.
- Production-сборка Vite.
- Реальные RTCPeerConnection в двух браузерах через локальный сервер протокола: одна ссылка, двусторонние медиапотоки, смена камеры с сохранением выключенного микрофона, отказ третьему клиенту без разрыва существующей пары, восстановление после обрыва сигнализации, завершение.
- Реальная облачная сигнализация Metered: двустороннее видео.
- Реальный Metered TURN с `iceTransportPolicy=relay`: двустороннее видео и ненулевое число входящих аудиопакетов на обоих клиентах; статистика подтверждает маршрут relay.
- Реальный Metered TURN/TLS: из ICE-конфигурации оставлены только `turns:` адреса, прямые кандидаты запрещены. Двустороннее видео и входящие аудиопакеты подтверждены на обоих клиентах.
- Авторизация нового publishable key: сервер вернул 5 ICE-настроек, включая 4 TURN URL и TLS.

В браузерных тестах использовались синтетические камера и микрофон Chrome, размер экрана 390×844. Проверка сети не равна проверке настоящего телефона: камера устройства, перегрев, энергосбережение и конкретный оператор могут дать другой результат. Из сети мамы в Беларуси звонок пока не проверен.

Команды воспроизведения: `npm test`, `npm run typecheck`, `npm run build`, `npm run test:e2e:metered`; облачный тест `npm run test:cloud` с `METERED_PUBLISHABLE_KEY` либо `CLEARCALL_URL`. Без облачных параметров тест пропускается и не считается пройденным.
